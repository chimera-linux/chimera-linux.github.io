The 20261103 set of images is now published.

This is an incremental refresh.

<!--more-->

## Changes

It wasn't originally planned to take a year refreshing the
images but here is finally a new version.

There isn't anything particularly special about the images
themselves but this comes with a full set of updates around
the system that happened in this year.

The most notable change that affects live usage is that the
base image now comes with NetworkManager, replacing iwd. That
should make networks easier to configure even for base systems
without GUI (wireless configuration and so on) while being
ready for removal of AF_ALG.

This set is based on kernel 7.3, GNOME 51, and Plasma 6.8.
Newly, none of them come with the X.org server.
